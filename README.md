# React Map Weather App 🌦️🗺️

A dynamic, interactive weather application built with React. Rather than just typing a city name, this app uses an interactive map to let users explore weather conditions globally. 

Select a city from the dropdown or interact with the map to fly to a location and view real-time weather data, alongside 48-hour and weekly forecasts.

## 🚀 Features

- **Interactive Map:** Powered by React Leaflet, allowing users to visually navigate and select locations.
- **Dynamic Fly-To:** Selecting a city automatically pans and zooms the map to the target location.
- **Comprehensive Weather Data:** 
  - Current temperature and conditions
  - 48-hour hourly forecast
  - 7-day weekly forecast
  - Detailed metrics: Wind speed, atmospheric pressure, sunrise/sunset times, and humidity.
- **Sleek UI:** Styled entirely with Tailwind CSS, utilizing Shadcn UI for accessible, polished dropdown components.
- **Responsive Design:** Fully functional and visually appealing on both mobile and desktop screens.

## 🛠️ Technologies Used

- **Frontend Framework:** React (Vite/Create React App)
- **Styling:** Tailwind CSS
- **UI Components:** Shadcn UI
- **Map Integration:** React Leaflet & Leaflet.js
- **Weather API:** [ OpenMeteo API ]
